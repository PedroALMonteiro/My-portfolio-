# Portfólio | Pedro Monteiro

Meu portfólio pessoal, feito com HTML, CSS e JavaScript puros. Sou estudante de Ciência da Computação na CESAR School e uso este site para reunir meus projetos, o que estudo e um pouco de quem sou fora do código.

**Site publicado:** [pedromonteiro-tau.vercel.app](https://pedromonteiro-tau.vercel.app)

## Páginas

| Página | O que tem |
| --- | --- |
| `index.html` | Apresentação, interesses profissionais, resumo do Projeto 1 e contato |
| `sobre.html` | Minha trajetória, o que me inspira, formação e o que gosto de fazer fora do código |
| `projetos.html` | ReciMap, Cofre Seguro e um jogo narrativo no-code |
| `estudos.html` | Linguagens e tecnologias do primeiro período, certificados e palestras |

## Tecnologias

- **HTML5** com tags semânticas (`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`)
- **CSS3** com Flexbox, Grid, variáveis CSS e layout responsivo
- **JavaScript** puro, sem bibliotecas:
  - botão que copia meu e-mail
  - ano do rodapé atualizado automaticamente
- **Markdown** neste README

## Como rodar localmente

Não precisa instalar nada. Baixe ou clone o repositório e abra o `index.html` no navegador.

```bash
git clone https://github.com/PedroALMonteiro/portfolio.git
cd portfolio
```

## Acessibilidade

- Link "Pular para o conteúdo" para quem navega pelo teclado
- Indicação da página atual no menu (`aria-current`)
- Aviso de "e-mail copiado" anunciado por leitores de tela (`role="status"`)
- Cores com bom contraste e foco visível

## Visual

Tema escuro e limpo, com detalhes inspirados no GTA San Andreas: títulos em fonte pesada com sombra dura (Bowlby One, do Google Fonts) e selos de status no clima de "missão". As cores ficam nas variáveis no começo de `css/style.css`.

Ícones das linguagens: [Devicon](https://devicon.dev/).
